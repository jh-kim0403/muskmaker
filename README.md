# MuskMaker

**AI-Powered Goal Completion & Rewards**

Complete your daily goals, get verified by AI, earn coins, and enter sweepstakes to win prizes.

> Currently in testing on TestFlight.

---

## Description

MuskMaker is a mobile app that helps you build habits and achieve goals through accountability and rewards. Set a goal (going to the gym, reading the Bible, attending class), complete it, and submit a photo as proof. For subscription users, AI verifies your submission using photo analysis and GPS location. Earn coins for every verified goal completion and spend them on sweepstakes entries for a chance to win prizes. Notifications are personalized and generated by AI to keep you on track.

---

## Features

- **Goal Tracking** — Create and manage daily personal goals
- **AI Verification** — OpenAI GPT-4o verifies goal completion via photo (+ GPS location for subscribers)
- **Coin Rewards** — Earn coins for each verified goal
- **Sweepstakes** — Enter prize drawings using earned coins
- **AI Notifications** — Personalized push notifications generated by AI
- **Subscription Tiers** — Free and premium tiers with different verification capabilities
- **Admin Dashboard** — Internal review queue for managing submissions

## Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/your-username/MuskMaker.git
cd MuskMaker
```

### 2. Backend Setup

```bash
cd backend

# Install dependencies (requires uv: https://docs.astral.sh/uv/)
uv sync

# Copy and fill in environment variables
cp .env.example .env

# Run database migrations
uv run alembic upgrade head

# Start the API server
uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# In a separate terminal, start the Celery worker
uv run celery -A app.celery_app worker --loglevel=info
```

### 3. Mobile Setup

```bash
cd mobile

# Install dependencies
npm install

# Copy and fill in environment variables
cp .env.development.example .env.development

# Start Expo dev server
npm run start:dev

# Run on a specific platform
npm run android:dev
npm run ios:dev
```

### 4. Admin Dashboard Setup

```bash
cd admin

# Install dependencies
npm install

# Copy and fill in environment variables
cp .env.example .env

# Start the dev server
npm run dev
```

## Environment Variables

### Backend (`backend/.env`)

```env
# Database
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/muskmaker

# Firebase
FIREBASE_PROJECT_ID=your-firebase-project-id
FIREBASE_SERVICE_ACCOUNT_PATH=./firebase-service-account.json

# AWS
AWS_ACCESS_KEY_ID=your-access-key
AWS_SECRET_ACCESS_KEY=your-secret-key
AWS_S3_BUCKET=your-bucket-name
AWS_CLOUDFRONT_DOMAIN=your-cloudfront-domain

# OpenAI
OPENAI_API_KEY=sk-...

# RabbitMQ
CELERY_BROKER_URL=amqp://guest:guest@localhost:5672//
```

### Mobile (`mobile/.env.development`)

```env
EXPO_PUBLIC_API_URL=http://192.168.1.x:8000
```

### Admin (`admin/.env`)

```env
VITE_API_URL=http://localhost:8000
```
